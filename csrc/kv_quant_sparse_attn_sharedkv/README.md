# `kv_quant_sparse_attn_sharedkv`

This directory contains the Ascend 950 (A5) quantized-KV sparse attention
operator. The kernel consumes BF16 queries and FP8 E4M3FN original/compressed
KV caches, and produces a BF16 attention output.

## Torch interface

The operator is registered as:

```python
out, softmax_lse = torch.ops.npu.kv_quant_sparse_attn_sharedkv(
    q, kv_quant_mode, ori_kv=..., cmp_kv=..., metadata=..., sinks=...,
    ori_block_table=..., cmp_block_table=..., seqused_kv=...,
    layout_q="BSND", layout_kv="PA_ND",
)
```

The remaining optional tensors and attributes mirror the schema in
`csrc/pytorch_extensions.cpp`. Optional tensor placeholders are created by the
host launcher for the device kernel; required inputs must be contiguous and on
the same NPU as `q`.

`metadata` is the flat `int32[1024]` schedule generated by
`kv_quant_sparse_attn_sharedkv_metadata`. The current A5 kernel path supports
BF16 `q`, FP8 E4M3FN KV, and the layouts accepted by the upstream tiler.

## Build

```bash
bash build.sh -a kernels Ascend950PR_9599
pip install output/sgl_kernel_npu*.whl
```

Graph capture should be preceded by an eager warm-up with identical tensor
shapes, optional-input presence, dtypes, and attributes so the tiling address is
cached.
